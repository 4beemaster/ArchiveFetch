Network

Off: only devices on this console's local network can use ArchiveFetch. On: devices that reach port 8890 from outside, for example through port forwarding, can use it after signing in with the password below. ArchiveFetch uses plain HTTP, so on untrusted networks (such as public Wi-Fi) the password can be read in transit.

Paired devices

The Windows and Android apps pair the first time they control this console, then connect without the password, also from outside. Remove a device to make it sign in with the password again.
